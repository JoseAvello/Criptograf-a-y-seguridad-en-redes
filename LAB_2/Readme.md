# Laboratorio 2 - Criptografía y Seguridad en Redes

Este repositorio contiene el desarrollo del Laboratorio 2, enfocado en el análisis de ataques de fuerza bruta sobre DVWA.

## Contenido

Durante el laboratorio se trabajó con:

- Docker para levantar DVWA.
- Burp Suite para interceptar y modificar solicitudes HTTP.
- cURL para realizar solicitudes manuales desde terminal.
- Hydra para automatizar ataques de fuerza bruta.
- Wireshark para analizar el tráfico generado por las distintas herramientas.

## Objetivo

El objetivo principal fue comprender cómo se comportan distintas herramientas al realizar intentos de autenticación y comparar las diferencias presentes en el tráfico HTTP generado.
